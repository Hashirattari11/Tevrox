3. DATABASE (Supabase PostgreSQL)
- Configure the connection through environment variables. Never hardcode secrets.
- Define SQLAlchemy models and the first Alembic migration for these tables:
  users, user_profiles, products, brands, ingredients, product_ingredients, data_sources, analyses, routines, routine_items, nutrition_entries, admin_audit_logs
- Requirements for the schema:
  - UUID primary keys, created_at / updated_at timestamps on all tables
  - Proper foreign keys with sensible ON DELETE behavior
  - Unique constraints (e.g., users.email, product barcode, product_ingredients composite uniqueness)
  - Indexes on search/lookup columns (barcode, product name, ingredient normalized name, user_id foreign keys)
  - users.role enum: user, admin
  - products: verification_status enum (unverified, verified, rejected), source reference to data_sources
  - ingredients: name, normalized_name (unique), description, reference notes
  - analyses: store user_id, product_id, structured_result (JSONB), model_used, created_at
  - routines: type enum (morning, evening)
  - routine_items: position/order field
- Run the migration against the dev database and confirm it applies and rolls back cleanly.
- Document the schema in docs/database/ with an ER diagram (Mermaid) and a table-by-table description.
